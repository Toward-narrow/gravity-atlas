02 / SWITCH THE INVISIBLE

重力，由你组装。

WGS‑84 纬度与扁率作为基底；其余因素可独立开关。点选因素卡片调整参数。

GEOMETRY / 高度

离地心远一点，重力就弱一点。

使用完整正常势计算观测高度的影响。左侧可输入椭球高，也可输入海拔并通过 EGM96 起伏 N 换算。

0 m 椭球面10 km

关闭此项只把正常场测点放回 h = 0；局部地质模型仍按其独立参数计算。h < 0 时使用正常势向下延拓，不代表真实地下密度。

ROTATION / 自转

越快的自转，越明显的离心作用。

下方自转滑块控制速度。关闭自转因素等于令离心项为零；引力势和地球形状固定。

对比基准始终是今天的地球。故关闭自转后，“自转变化”贡献通常为正。潮汐星历继续采用真实地球的方位，不模拟假想自转历史。

ROCK / 等效岩层

脚下额外的岩石，也在吸引你。

无限水平板近似：向下加速度 2πGρt。适合解释广阔平坦岩层；厚度和密度是你设定的场景。

这是附加等效板的正演吸引，不是已完成的布格改正，也不是周围真实山体的 DEM 积分。取海拔作厚度只是一种平板教学近似。

GEOLOGY / 密度异常

看不见的矿体，会留下重力信号。

均匀球体相对背景岩石的密度差 Δρ。正值模拟致密矿体，负值模拟低密度体。

深度与偏移均相对测点；深度须 ≥ 半径。改变全球地点时保留此假想局部模型。下方可拖动球体，直接改变位置。

HYDROLOGY / 地下水

一场雨之后，地下储水也会改变重力。

测点下方广阔储水层的质量增减，用等效水厚 EWH 表示；正值为新增储水，负值为减少。

Δg = 2πGρ水Δt，ρ水 = 1000 kg/m³。不是直接输入地下水位；水位变化需结合含水层给水度换算。未包含地面变形。

TIME / 日月引潮

同一个位置，重力也随时间轻轻起伏。

按日月星历计算测点与地心所受吸引之差。经度、纬度与时刻共同影响结果。

+0.0 h

刚性地球的直接引潮加速度；未加入弹性固体潮、海潮负荷与极潮，不能作为精密重力仪的完整潮汐改正。

BEHIND THE NUMBERS

一个基底，六类可选因素。

使用 WGS‑84 旋转椭球的外部正常引力势。纬度为大地纬度，h 为椭球高，支持椭球高 −1–100 km；负高程使用正常势的数学向下延拓。所有输入均以 SI 单位参与计算。

正常场：g⃗ = ∇V + a⃗c　 ·　 F⃗ = m g⃗
a⃗c = ω² (x, y, 0)

引力势使用闭式椭球模型，而非点质量 GM/r²。先将大地坐标转换为地心坐标，再求势函数解析梯度，最后转换到当地东、北、天坐标。

V = (GM/E) arctan(E/u)
　+ ½ω₀²a²(q/q₀)(sin²β − ⅓)
q = ½[(1 + 3u²/E²) arctan(E/u) − 3u/E]
E = √(a² − b²)，q₀ = q(b)
ρ = √(u² + E²) cosβ，z = u sinβ

u、β 为扁球坐标。程序用收敛级数计算 q 及其导数，减少相近数相减导致的精度损失。ω₀ 是真实自转角速度；实验中的自转倍率仅作用于离心加速度。

为什么经度改变了，大小没变？

正常场轴对称：相同纬度和椭球高的加速度大小相同。经度改变地心坐标中的方向。新增的日月引潮随经度和时刻变化；真实 DEM 高程也随经纬度变化。地下球体、等效岩层和储水变化是手动设置的局部假想模型，不是按坐标查到的真实地质。全球场图另用 GFZ EIGEN-6C4 截断到 179 阶展示重力扰动与大地水准面；该图层暂不叠加进当地数值计算。

高度与力的含义

椭球高 h 不等于海拔 H；二者通过大地水准面起伏 N 联系：h = H + N。默认启用“测点随地表”，定位后自动读取本地 ETOPO 2022；关闭后保留手动高度。读取高程采用 DEM 网格高度，珠峰点的 DEM 值不等于测量峰顶高度。加速度与测试物体质量无关，力（N）等于质量（kg）乘以加速度（m/s²）。离心力在随地球旋转的参考系中定义，默认物体相对地球静止。

显示小数用于比较模型计算，不代表当地实测精度。地球图采用球形地理投影；计算使用真实 WGS‑84 扁率。

新增模型与符号

总矢量 = 正常引力 + 离心加速度 + 等效岩层吸引 + 球体密度异常 + 地下储水变化 + 日月直接引潮。质量仅影响力（N），不影响加速度。

岩层 / 储水板：aᵤ = −2πGρt
球体外部：a⃗ = G(4πR³Δρ/3) d⃗ / |d⃗|³
引潮：a⃗ₜ = GM[(R⃗ − r⃗)/|R⃗ − r⃗|³ − R⃗/|R⃗|³]
G = 6.67430 × 10⁻¹¹ m³ kg⁻¹ s⁻²

板模型假定测点位于板上方；球体方向 d⃗ 从测点指向球心。岩层与球体可以叠加，但球体必须使用相对背景的密度差，以免把背景岩石重复计入。实际山谷地形需要周边高分辨率 DEM 的体积积分，不能由单点海拔确定。

真实全球地形与误差范围

已内置 NOAA ETOPO 2022 v1 全球 60″ 地表 / 海底高程和配套 EGM2008 大地水准面数据。原始全球网格为 21600 × 10800，约 2.33 亿格点；1′ 在赤道约 1.85 km。这是网格间距，不是垂直精度。

地球着色与悬停预览使用 10′ 均值格网及明暗地形纹理；点击读取最近的原始 1′ 网格（高程量化到 1 m，水准面起伏到 0.01 m）。h = H + N，ETOPO 高程必须配套 EGM2008，不能直接与旧版 EGM96 混用。地形测点使用 EGM2008；未读取地形的手动高度保留旧版 EGM96 参考。

海洋测点默认取海面 H = 0，另显示海底深度。海陆判别由 10′ 负高程连通区估计，狭窄海湾与沿岸可能误判，可关闭随地表并手动设高度；陆地负海拔盆地保留负值。冰区使用冰面而非冰下基岩。

地形目前改变测点高度，并不自动加入山体质量的吸引。山体引力需要周边地形体积分及密度假设；此处未加载完整 EGM2008 重力球谐场。日月引潮仍为刚性地球近似。
